# denypm.id

Halaman profil & layanan denypm.id — https://denypm.pages.dev

## Cara mengubah isi
Semua teks, link, layanan, produk, dan mitra ada di `index.html`, di bagian
`const DATA = { ... }` (cari tulisan "UBAH ISI DI SINI SAJA").

- Produk andalan: isi `produk: [ ... ]` (contoh formatnya ada di komentar tepat di atasnya).
- Toko Lynk: `tokoLynk`.
- Gambar: taruh di folder `img/`.

Setiap perubahan yang di-commit ke branch `main` otomatis tayang di Cloudflare Pages dalam ±1 menit.
